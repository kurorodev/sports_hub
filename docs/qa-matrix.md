# Матрица серверной проверки

Автоматические JUnit/MockMvc-тесты выполнены: **23 теста прошли, ошибок и пропусков нет**, включая S1–S6 и тест сохранения CSRF после нескольких запросов. Использовалась H2 в PostgreSQL mode с реальными Spring Security, JPA, Flyway и сервисами. Профиль `postgres-it` повторяет сценарии на настоящем PostgreSQL и добавляет конкурентные проверки; он пока не запускался из-за недоступного Docker. Серверные тесты не проверяют UI и адаптивность.

| Сценарий | Позитивная проверка | Негативная/граничная проверка | Автотест |
|---|---|---|---|

| S2 | Заявка PENDING, APPROVED, публикация от организации, REJECTED с причиной | Запрет до допуска/после отказа; отсутствие причины; чужое решение | CoreScenariosTest |

| S5 | Вопрос без записи, ответ автора, сохранение авторства | Скрытие только выбранного сообщения; запрет обычному пользователю | CoreScenariosTest |

HTTP-smoke на работающем сервере: `python3 scripts/smoke.py`. Он проверяет шесть P0, очередь и чаты без SQL-правок. Он выполнен пользователем на работающем backend/PostgreSQL: в `smoke-latest.log` все S1–S6, очередь и чаты успешны.

Оставшиеся проверки перед сдачей: полный профиль PostgreSQL/Testcontainers, включая конкурентные тесты; frontend↔backend e2e, поведение браузерных cookies/CORS/HTTPS, публичная доступность по сети. Публичный интерфейс и UX оцениваются после реализации frontend.
