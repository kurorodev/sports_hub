# Упрощение профиля и отмена геймификации

Решением пользователя в `fix/theme/ui` основная тема светлая; предпочтение темы устройства больше не влияет на первое открытие. Явно сохранённая тёмная тема продолжает работать. В собственном и публичном профиле удалены очки, ранг и блок с описанием начислений. Уровень владения конкретным видом спорта (начинающий, любитель и т. д.) сохранён: это характеристика спортивных интересов.

Выбираемые спортивные роли: `ATHLETE`, `SPORTS_ORGANIZER`. Миграция V13 удаляет `COACH` и `REFEREE` из существующих профилей. PATCH профиля отклоняет эти роли с 400. Сервер также фильтрует старые роли при формировании профилей, сессий, авторов сообщений, участников и списка демоаккаунтов. Клиент умеет читать старые сохранённые данные, скрывает удалённые роли и не отправляет их обратно. Системные роли и права администратора/представителя организации не менялись.

Начисление очков и назначение судей отключены, включая прямые запросы к API. Два прежних POST `/competitions/{eventId}/referees` и `/competitions/{eventId}/participations/{registrationId}/verify` возвращают 410 после проверки входа, без записи в БД. Демоинициализация больше не создаёт назначения судей и проводки рейтинга.

Для совместимости клиентов поля `rank` и `ratingPoints` в прежних DTO сохранены: всегда `ROOKIE` и 0. Они не используются в модели профиля frontend. Старый GET рейтинга возвращает нейтральные значения с `rulesVersion: disabled`, GET истории — пустую страницу. Операции помечены deprecated в OpenAPI. Старые значения enum COACH/REFEREE сохранены в транспортном справочнике только для совместимости чтения; входной контракт PATCH разрешает две действующие роли. Настройки начислений и порогов рангов удалены из конфигурации.

Исторические таблицы и записи не удаляются. Отмена геймификации не изменяет мероприятия, записи на них, обсуждения и историю прежних действий.

Проверки: `mvn verify` — 86 тестов; Vitest профиля, API-модели и настроек — 49 тестов; Playwright на 375/1440 px — светлый первый запуск при тёмной теме ОС, сохранение ручной тёмной темы, две доступные роли и отсутствие рейтинга в собственном/публичном профиле.

PostgreSQL/Testcontainers: 5 конкурентных сценариев прошли, включая два одновременных запроса к отключённому начислению очков. Production build, TypeScript и проверка OpenAPI проходят.

Дополнение `fix/smalltalk`: выбор спортивных ролей теперь доступен только представителю одобренной организации. Обычный пользователь может сохранять остальные поля с неизменённым набором ролей. [Подробности и проверки](smalltalk-fixes.md).
