# Единый раздел организаций

В шапке один пункт **«Организации»**. Каталог и кабинет используют общий экран и две ссылки переключения:

- `/organizations` — публичный каталог одобренных клубов, поиск и страницы организаций.
- `/organizations?view=mine` — свои организации, статусы заявок, причины отказа и создание встреч после одобрения.
- `/organizations?view=apply` — отдельная форма новой заявки.

Поиск и страница каталога сохраняются при переключении между разделами. Ссылки можно открывать напрямую, обновлять и использовать с кнопками браузера «Назад»/«Вперёд». Старый `/organization` перенаправляет в «Мои организации»; старые уведомления и закладки продолжают работать.

Гость может пользоваться каталогом. В личном разделе и форме есть вход с возвратом к выбранному действию. При смене пользователя прежний личный кабинет размонтируется существующим Layout и приватный query-кэш очищается переходом сессии.

## Заявка и управление

Форма открывается действием «Добавить организацию» и не занимает место среди карточек. Виды спорта необязательны: поиск показывает подходящие направления, пустой поиск — только уже выбранные. Выбор нескольких направлений сохраняется при изменении поискового запроса.

После успешного ответа 201 открываются «Мои организации», показываются карточка со статусом рассмотрения и временное уведомление. При ошибке форма сохраняет данные; повторные отправки блокируются на время запроса.

Одобрение и отказ продолжают приходить при опросе API каждые 10 секунд; есть ручное обновление. Одобрение обновляет сессию и открывает создание встречи от организации. Ожидающая или отклонённая заявка не даёт права публикации. Существующая модерация администратора остаётся в `/admin`.

## Компоненты

`OrganizationsPage` содержит общую навигацию и проверку входа. `OrganizationsDirectory` отвечает за поиск и пагинацию, `MyOrganizations` — за свои карточки и статусы, `OrganizationApplication` — за загрузку справочника и композицию формы. Контракт Java API, модели прав и база данных не менялись.

## Проверки

Прошли 43 профильных Vitest, lint и production build. Chromium проверил навигацию, возврат после входа, поиск, несколько выбранных видов спорта, новую заявку и старый URL на 375/768/1440 px; основные страницы и права — на 320–1440 px. Прежний сквозной сценарий обеих ветвей модерации и публикации прошёл на моках в пяти размерах. На отдельном Java/PostgreSQL-стенде сценарий одобрения, отказа и публикации проверен на 375 px с независимыми сессиями.

Для старого `sports-categories.spec.ts` требуется актуализация ожидания 202 элементов `option` у поля «Категория спорта»: поле уже заменено в master на компонент поиска. Этот тест останавливается до проверки формы организации. Выбор нескольких направлений в новой форме покрыт `organization-hub.spec.ts`.
