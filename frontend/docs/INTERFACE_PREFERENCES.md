# Язык и тема интерфейса

В собственном профиле (`/profile`, в том числе при редактировании) доступен блок «Настройки интерфейса». Переключатели RU/EN и светлой/тёмной темы применяются сразу, без отправки формы профиля и без сброса введённых данных. В публичном профиле другого пользователя этот блок не отображается.

Выбор хранится в браузере в `localStorage` под ключом `sport.interface.v1`: `{ "locale": "ru", "theme": "light" }`. Настройки общие для аккаунтов в этом браузере, сохраняются при выходе и перезагрузке, синхронизируются между вкладками. Синхронизации между устройствами нет, API профиля не менялся. По умолчанию язык русский, тема светлая независимо от настройки устройства при первом открытии. При недоступном хранилище переключатели работают до перезагрузки.

Тема задаётся через `html[data-theme]`, семантические CSS-переменные и `color-scheme`. Небольшой скрипт в `index.html` применяет сохранённый выбор до загрузки React, чтобы избежать вспышки светлой страницы. Логотип выбирает подходящий вариант для фона. Фирменный жёлтый цвет сохраняется, текст на нём использует отдельный цвет с достаточным контрастом.

Русские исходные строки интерфейса передаются в `tr` из `src/shared/i18n/translate.ts`. Английский словарь находится в `en.json`. Компоненты подписываются через `useLocale()` или `usePreferences()`; обычные функции форматирования получают текущую локаль через `localeTag()`. Календарь, относительное время, даты и расстояния учитывают язык. Имя приложения по-прежнему берётся из общего `branding.json`.

Для нового текста добавьте пару в словарь и используйте `tr("Русский текст")`. Для динамических значений используйте `tr("Организатор: {0}", [displayName])`: пользовательское значение подставляется без перевода. Названия и описания мероприятий, организаций и видов спорта из API, имена, города, адреса, комментарии, переписка и серверные уведомления/причины сохраняются в исходном виде. Не передавайте пользовательские тексты в `tr`.

## Проверки

Добавлены три проверки переключения, независимого сохранения настроек, работы без хранилища, обновления из другой вкладки, форматирования и сохранения исходного текста в подстановках. Playwright проверяет RU/EN, обе темы, перезагрузку, переходы по страницам и сохранение черновика профиля на 375 и 1440 px.

Полный Vitest: 328 прошли, 14 упали. Все 14 воспроизведены на неизменённом master `7b03a03`: 3 теста диапазона дат, 2 заявок, по одному модерации, организаций, геолокации и поддержки (ожидания прежних нативных полей и доступных имён), 5 регистрации (несовместимость WebCrypto/ArrayBuffer в тестовом окружении). Новых падений нет. Общий ESLint останавливается на прежнем предупреждении `Textarea.tsx` о зависимостях `useLayoutEffect`; ошибок ESLint нет.
