# Выбор города

Ветка `fix/city-selection`: каталог, профиль, анкета, создание мероприятия,
добавление площадки, предложение площадки в поддержку и его публикация
используют общий `CitySelect`. По мере ввода показываются города из справочника;
поисковый текст не становится значением формы. Выбор доступен мышью и клавиатурой.
В каталоге можно выбрать все города, в профиле — оставить город неуказанным.

Подсказка адреса и обратное геокодирование автоматически подставляют город,
если он есть в справочнике. Если город не распознан, требуется выбрать его из
подсказок. Адрес и точка сохраняются для дальнейшего заполнения формы.

Источник — существующий `src/shared/model/russian-cities.json` с метаданными
источника и лицензии. Его копия `backend/src/main/resources/russian-cities.json`
нужна серверу для проверки входящих данных. При обновлении справочника обе копии
обновляются вместе. Сервер отклоняет выдуманные названия и приводит допустимые
варианты регистра, пробелов и «е/ё» к названию из справочника. Новые ограничения
применяются при записи; чтение старых данных не блокируется.

Форматы запросов и ответов сохранены, описания полей в OpenAPI уточнены.
Миграции базы не нужны. Надпись «Не нашёл свой спорт? Добавь его сам.» удалена
со страницы создания мероприятия.
