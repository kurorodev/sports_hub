# Иллюстрации и аватары

Ветка `fix/images` создана от master. Использованы файлы пользователя из `assets/`:

- Спортивная панорама — главный экран и обложка мероприятий для категорий без отдельной иллюстрации.
- Лёгкая атлетика, баскетбол, футбол, теннис, настольный теннис, волейбол, шахматы и лыжные дисциплины — собственные иллюстрации в карточках, на странице мероприятия, в быстрых категориях и поиске категорий каталога/карты.
- Из архива `sport_avatars_10_svg_png.zip` использованы 10 настоящих векторных SVG: пять мужских и пять женских персонажей. Для каждого подготовлены три варианта формы; при перекраске сохраняются цвета лица и волос.

Готовые файлы находятся в `public/art/sports/` (JPEG, около 1 МБ суммарно) и `public/avatars/{user,organizer,admin}/` (30 SVG, около 1,7 МБ). PNG-контейнеры из `svg_exact_appearance` не используются. Повторная подготовка на macOS: положить исходные файлы в корневую `assets/` и выполнить `python3 frontend/scripts/prepare-images.py`. Для запуска проекта исходный архив не нужен: подготовленные файлы входят в Git. Исходные пользовательские файлы остаются локально без изменений.

## Выбор персонажа

`/profile` → «Редактировать профиль» → выбрать персонажа → «Сохранить профиль». Есть предварительный просмотр, отметка выбранного персонажа, сброс и прежний вариант своего изображения по ссылке. Изменение сохраняется существующим PATCH `/me/profile`, отражается в публичном профиле, шапке, карточке организатора, обсуждениях и участниках. После отмены форма ничего не сохраняет. Список спортивных интересов ограничен по высоте и прокручивается, чтобы кнопка сохранения оставалась доступной без длинного прокручивания страницы.

Цвет встроенного аватара определяет backend:

| Контекст | Форма |
| --- | --- |
| Обычный пользователь, участник чужой встречи | Синяя |
| Организатор своей встречи, в том числе в обсуждениях и заявках | Красная |
| Профиль представителя одобренной организации | Красная |
| Представитель организации на рассмотрении или с отказом, обычный участник | Синяя |
| Администратор в любом контексте | Жёлтая |

Персонаж не меняется при переключении контекста. Спортивная специализация SPORTS_ORGANIZER сама по себе не меняет системные права или допуск организации. Свои фотографии по URL сохраняют исходный вид.

API использует `avatarUrl`: встроенный путь `/avatars/{user|organizer|admin}/{male|female}-0[1-5].svg` либо безопасный внешний http/https URL. Для пользователя сервер сохраняет встроенный персонаж в каноническом варианте `user`, а возвращаемый цвет вычисляет при чтении. Отправка пути `admin` обычным пользователем не делает его администратором и не даёт жёлтую форму. Неизвестные локальные пути, обход каталогов, javascript/data URL и URL с логином/паролем отклоняются. `null` сбрасывает выбор на стабильный автоматический персонаж. Контракт avatarUrl для PublicUser/UserProfile/ProfilePatch/OrganizerSummary теперь допускает URI-reference; набор API-операций и схема БД не изменены. Логотипы организаций по-прежнему используют внешний URL.

## Проверка вручную

1. Пользователем выбрать персонажа и сохранить; обновить профиль и открыть его публичную страницу.
2. Посмотреть тот же персонаж красным у организатора своей встречи и синим в участниках чужой встречи.
3. Открыть профиль администратора: выбор и отображение используют жёлтую форму.
4. Отменить выбор другого персонажа: сохранённый профиль остаётся прежним.
5. Проверить новые изображения на главной, в каталоге, мероприятии и выборе категории на карте.

Браузерная проверка этой задачи не создаёт мероприятий, площадок и аккаунтов в ручной БД. Примерка аватаров завершается отменой; сохранение и проверки прав выполняются на изолированных H2/PostgreSQL и MSW.
