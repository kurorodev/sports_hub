# Подсказки городов

Фильтр каталога использует локальный снимок [HFLabs / DaData «Города России»](https://github.com/hflabs/city), полученный 20.10.2026. Исходные данные распространяются по [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/); производный справочник `src/shared/model/russian-cities.json` сохраняет эту лицензию. Метаданные файла содержат атрибуцию и SHA-256 исходного CSV.

Из CSV извлечены названия городов, включая города федерального значения; одинаковые названия объединены, порядок подсказок основан на населении из исходного снимка. Это локальный справочник городов России, а не результат геопоиска или список городов текущих мероприятий. Он не требует ключа Geoapify; обновляется заменой снимка.

Показывается до трёх совпадений по началу названия без учёта регистра и различия е/ё. Выбрать можно только существующий вариант; Enter при отсутствии совпадений не применяет введённый текст. Неизвестный город из старого URL удаляется, регистр известного приводится к справочнику. API продолжает получать каноническое название в прежнем параметре `city`.

Для этой доработки тесты и сборка не запускались по просьбе владельца продукта. Ручная проверка: «Сам» → Самара, «Самравалв» → пустой список и отсутствие применения по Enter, сброс через «Все города», обновление страницы с выбранным городом.
