# Стечение · frontend

Сторис от администрации на главной и в «Модерация → Сторис»: публикация только админом, фиксированный срок 24 часа, досрочное удаление и личная отметка просмотра. [API, возможности и ручная проверка](../backend/docs/stories.md). Для настоящих данных требуется backend с миграцией V14; в mock mode публикации доступны только в текущем браузере.

Анкета после регистрации, повторное заполнение и персональная подборка: [описание сценариев и API](../backend/docs/questionnaire.md).

Иллюстрации и выбор персонажа в профиле: [изображения, аватары и цвет формы по роли](docs/IMAGES.md).

Поддержка: `/support` — личные обращения, помощь, ошибки, идеи и предложения площадок; `/support?view=queue` — очередь администратора. В обсуждении доступна жалоба на комментарий. Ответы приходят в обращение и колокольчик. [Права, API и ручная проверка](../backend/docs/support.md).

Реализованы P0 shell/session, каталог, S1 (личная встреча с официальным видом спорта или своей активностью в «Другое»), S3 (OPEN-запись и участники), S4 (заявки с решением организатора), S5 (публичное обсуждение встречи), S2 (допуск организаций и публикация от их имени) и S6 (модерация мероприятий/комментариев). React 19 + TypeScript strict + Vite 7; точные версии закреплены `package-lock.json`.

**Java API подключён** для сессии, каталога и сценариев S1–S6. Сквозной браузерный путь проверен с PostgreSQL на 375/768/1440 px. Типы генерируются из `../backend/contracts/openapi.yaml`. Границы интеграции описаны в [API_REVIEW.md](docs/API_REVIEW.md).

Доступны личный профиль `/profile` с редактированием, публичный `/users/:userId` и демонстрационная регистрация `/register`. Регистрация создаёт аккаунт с паролем; повторный вход — по `@nickname` и паролю на `/login`. Старые демоаккаунты остаются доступны отдельным списком. Условия участия сохраняются при создании встречи и отображаются на её странице. Организатор доступен по ссылке из каталога, встречи и административного списка.

Поиск по названию и описанию в каталоге применяется автоматически через 300 мс после ввода; Enter и «Найти» применяют текст сразу. Очистка поля убирает текстовый фильтр, остальные фильтры сохраняются, страница выдачи сбрасывается. Используется существующий `GET /events?q=…`; во время загрузки предыдущие карточки остаются на экране. Java и моки допускают небольшие опечатки в словах от пяти символов — [правила и ограничения поиска](../backend/docs/event-search.md). Ручная проверка: ввод и удаление текста, Enter, сочетание с городом, сброс фильтров и переходы назад/вперёд.

## Быстрый запуск

Node.js 22.12+ или совместимая современная версия, npm. Если `backend/.env` ещё нет, создайте его копией `backend/.env.example`; существующие настройки сохраняйте.

```sh
# Из корня репозитория; требуется запущенный Docker / OrbStack
docker compose --env-file backend/.env -p sport -f backend/compose.yaml up --build -d

cd frontend
npm ci
npm run dev         # Java API на localhost:8080, .env.real
```

Откройте `http://localhost:3000`. Порт разработки закреплён в Vite: если он занят, запуск завершится с ошибкой вместо автоматического выбора другого порта. На `/login` демоаккаунты загружаются отдельным списком с Java, без паролей: Алексей (`athlete-a`), Мария (`athlete-b`), Ирина (`athlete-c`), тренер (`coach`), представители организаций и администратор (`admin`). После смены режима перезапустите Vite.

```sh
npm run dev:mock    # отдельный режим сетевых моков, .env.mock
npm run build      # production real mode
npm run build:mock # демонстрационная сборка на моках
npm run api:generate # после изменения OpenAPI
npm run api:check
npm run sports:check # синхронизация справочника моков с backend
npm run typecheck
npm run lint
npm test
npm run test:e2e    # моки; перед первым запуском: npx playwright install chromium
npm run test:e2e:api # Java + PostgreSQL; CORS-настройка — в docs/DEVELOPMENT.md
```

Все шесть основных сценариев подключены. Следующий этап — общая приёмка, доступность и развёртывание, затем самостоятельные P1/P2-сценарии. Организации: `/organizations`, свои заявки: `/organizations?view=mine`, админка: `/admin` (организации), `/admin?section=events` и `/admin?section=comments`. Причины снятия события и скрытия комментария доставляются адресатам через колокольчик — [API_REVIEW.md](docs/API_REVIEW.md).

Карта доступна в шапке и через «Список / На карте» в каталоге: мероприятия, площадки, выбор места и оценки загруженности. Выбранный объект и область сохраняются при возврате со встречи; место встречи можно открыть на мини-карте. Настройка геокодера, границы фильтров и QA-пути описаны в [MAPS.md](docs/MAPS.md).

Расстояние от текущей геопозиции доступно на карточках и в фильтре «Рядом со мной»: 100/200/500 м и 1/2/3/5 км. [Правила, разрешение GPS и HTTPS](../backend/docs/event-distance.md).

Справочник категорий: [200 видов спорта из снимка ВРВС и «Другое»](../backend/docs/sports-catalog.md). Пользовательское название не создаёт новую общую категорию. Версия источника и границы актуальности указаны в документе.

В обсуждении встречи можно отметить человека: начните вводить `@nickname`, выберите подсказку и отправьте сообщение. Отметка ведёт в профиль и сохраняет привязку после смены никнейма. Подробности входа и упоминаний: [пароли и упоминания](../backend/docs/passwords-and-mentions.md).

При наведении на организатора в каталоге, на странице встречи или в списке модерации открывается карточка с краткой информацией. Кнопка `@nickname` копирует никнейм вместе с `@` для вставки в обсуждение. На телефоне карточка открывается кнопкой ⓘ, с клавиатуры — фокусом; Escape закрывает её. Для организации отображается никнейм её представителя: собственного никнейма организации в API нет. Копирование поддерживает HTTP в локальной сети; при отказе браузера доступно ручное выделение.

Для вошедших пользователей в шапке доступен колокольчик: статусы заявок и встреч, личные причины модерации, упоминания и напоминания. Лента за 30 дней, время относительно текущего, прочитанное сохраняется. [API, получатели и настройки](../backend/docs/notifications.md). Причины снятия публикации/скрытия комментария отображаются только в этом окне.
